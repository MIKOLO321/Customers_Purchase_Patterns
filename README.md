### Business Problem Statement
A well-reputed retail firm aims to gain valuable insights about the customer purchasing behavior to increase revenue, boost customer satisfaction, and foster loyalty. In light of recent changes in the customers’ purchasing pattern based on demographic differences, product type, and sale channels (online vs. offline), there is a need for data-based assessment of consumer behavior.

Specifically, the firm is interested in learning about those important determinants of purchase behavior and repeat purchases such as discounts, customer rating, seasonality, and method of payment.

As a data analyst, you are expected to analyze consumer purchasing data to answer the following business problem:
“Which strategy should the firm use to gain insights from consumer purchasing data?”

### Deliverables of the Project
1.Data Preparation & Modeling (Python):
Performed various operations such as cleaning, transformation, and feature engineering on raw transactional data to make it suitable for analysis and modeling.

2.Data Analysis (SQL):
Performed data structuring, business simulation by creating relational tables and running SQL queries to derive insights on customer segmentation, loyalty, and drivers of purchases.

3.Visualization & Insights (Power BI):
Built an interactive Power BI dashboard to visualize trends, performance indicators, and customer behaviors for data-driven decision-making.

4.Analytical Report & Presentation:
Prepared an analytical report and made a presentation that includes important insights and recommendations for the business.

5.GitHub Repository:
Developed a GitHub repository with all the necessary Python scripts, SQL queries and Power BI files.
